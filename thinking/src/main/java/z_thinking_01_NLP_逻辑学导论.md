# 命题与论证
逻辑学是研究用于区分正确推理与不正确推理的方法和原理的学问。

[命题是推理的构建基块]。一个命题断定事情是如此这般或者不是如此这般。我们可以肯定或否定一个命题，但是，每个命题都或者断定了事情是或不是如此这般。
因此，[每一个命题都是或真或假的]

```
所有句子都是命题吗？

不是。
来自《逻辑学导论》定义：
命题：是或真或假的陈述。
句子是语法概念；命题是逻辑概念。
一个语法上完整的句子，不一定表达命题。
四类句子，哪些是命题

陈述句（描述事实、做出断言）→ 一般是命题
地球是圆的。
今天气温很高。
👉可以判断真假，属于命题。

疑问句 → 不是命题
你吃饭了吗？
为什么贫困问题如此严重？
👉只是提出问题，不做真假断言，无所谓真、无所谓假，不是命题。

祈使句（命令、请求）→ 不是命题
把门关上。
请帮助贫困儿童。
👉发出指令，不是在陈述 “什么是真的”，没有真假，不是命题。

感叹句（单纯抒发情绪）→ 不是命题
多么悲惨啊！
太可怕了！
👉单纯情绪宣泄，没有做出可判断真假断言。

注意区分：带感叹号的句子不一定都不是命题。
“每年有一千万儿童死于贫困！”—— 这是带感叹语气的陈述句，依然是命题，可以判断真假。只是加了情绪语气。
```
[我们使用命题这种建筑基块构造论证。在任一论证中，我们都是在一个或者更多其他命题的基础之上断定一个命题]，这样做就形成一个推论(inference)：一个命题被从一个或多个其他命题推出

[逻辑学家分析这些命题之间的关系，考察一个推论的起始命题与结束命题。这样的一个命题簇就构成一个论证]。论证是逻辑学所关心的主要对象。

## 演绎论证
它断言如果其前提都是真的，其结论一定是真的。不是一个程度问题，不以任何其他事物情况为转移
有效论证 + 全部前提为真 → 可靠论证，结论必然为真
[演绎是保真推理]
## 归纳论证
我们可以说归纳论证“较好”或“较差”，“较弱”或“较强，是一个程度问题，其程度受可能出现的其他事物情况的影响
前提对结论是或然（概率）支持。前提只能提升结论成立概率，无法保证结论一定为真；
[演绎讲有效无效（必然）；归纳讲强弱（概率）]

```
求同法
多个不同场景，结果都出现；这些场景唯一共同的先行因素，很可能就是原因。
结构：
案例 1：A B C →现象 X
案例 2：A D E →现象 X
案例 3：A F G →现象 X
推测：A 是 X 的原因
弱点：
可能存在隐藏共同因素，表面 A 相同，真正原因是隐藏的 H；
多因一果：现象 X 可以由不同原因分别造成。


求异法（差异法）
两组案例，除了一个条件 A 不同，其余全部条件一样；有 A 就出现 X，去掉 A 就不出现 X。推测 A 是 X 原因。
案例 1：A B C →X
案例 2：‑ B C →无 X
推测：A 是 X 的原因。
这就是对照实验底层逻辑。一组实验组，一组对照组，只改变一个变量。
求异法在五法当中，归纳强度相对更高。
风险：两组之间除 A 之外，还有别的未察觉变量发生变化。


共变法
当因素 A 发生程度增减变化，现象 X 也随之发生增减变化，则 A 与 X 存在因果关联。
A 增大，X 增大；A 减小，X 减小。
不要求现象完全出现 / 消失，只看程度的联动变化。适合无法把变量完全消除的场景。
例：温度升高，气体体积膨胀。
```

# 语言的功能
语言的三种基本功能
信息性功能（陈述功能）：用来断言命题、传递事实，有真假。逻辑论证主要使用这个功能

表达性功能：抒发情绪、态度、感受，不重在陈述事实。诗歌、感叹、评价。

指令性功能：用来发出命令、请求、规劝，引导行为。

```
事实论争：双方对客观事实判断不一样，可以通过证据去解决。

言辞论争（口头之争）：事实没有分歧，仅仅因为关键词定义不一样，产生虚假冲突。
例子：A 说 “这个人富裕”，B 说 “这个人不富裕”。两个人对 “富裕” 标准不一样，事实认知一致，只是词的定义不同。
同一个客观事实，可以选用带有褒义 / 贬义的词汇，带上情感色彩，改变人的判断，但事实本身没变。
同样一件事：“坚定”（褒义） / “固执”（贬义）。

混合型论争：既有事实分歧，又有词语定义歧义。
解决言辞之争的方法：澄清关键术语的定义。现实大量网络辩论，本质就是言辞论争。
```



# 非形式谬误
不是形式无效，是内容、语言、心理陷阱导致坏论证

## 不相干谬误
1.人身攻击:不去反驳对方论点，攻击说话者本人：人格、处境、动机。

2.诉诸情感:用怜悯、情绪博取认同，而不是提供证据

3.诉诸暴力:用威胁、强迫、压力代替逻辑证明。不讲道理：不听就要承受后果

4.诉诸大众:大家都这么认为，所以就是真的。多数人的信念不等于事实

5.稻草人谬误:刻意歪曲简化对手观点，树立一个容易打倒的虚假版本，然后反驳这个被歪曲的版本，假装驳倒对方

6.转移话题:故意扯另一个无关话题，把讨论主线带偏，回避原有论证。

## 不当归纳谬误
前提和结论有一定相关性，但是证据强度太弱，不足以支撑结论。

## 预设谬误
论证里面悄悄埋藏未经证明、有争议的假设，把假设当成事实直接使用。逻辑链条形式通顺，但地基是可疑预设

## 歧义谬误
同一个词语 / 句子，在论证不同位置使用不同含义，偷换语义造成欺骗性推理。

1.语词歧义:同一个词，前后两个地方取不同词义。

2.双关（句法歧义）:句子语法结构模糊，产生两种解读。
