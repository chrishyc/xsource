# 什么是逻辑学
逻辑学是研究用于区分正确推理与不正确推理的方法和原理的学问。

[命题是推理的构建基块]。[一个命题断定事情是如此这般或者不是如此这般]。我们可以肯定或否定一个命题，但是，每个命题都或者断定了事情是或不是如此这般。因此，每一个命题都是或真或假的

```
所有句子都是命题吗？

不是。
来自《逻辑学导论》定义：
命题：是或真或假的陈述。
句子是语法概念；命题是逻辑概念。
一个语法上完整的句子，不一定表达命题。
四类句子，哪些是命题

陈述句（描述事实、做出断言）→ 一般是命题
地球是圆的。
今天气温很高。
👉可以判断真假，属于命题。

疑问句 → 不是命题
你吃饭了吗？
为什么贫困问题如此严重？
👉只是提出问题，不做真假断言，无所谓真、无所谓假，不是命题。

祈使句（命令、请求）→ 不是命题
把门关上。
请帮助贫困儿童。
👉发出指令，不是在陈述 “什么是真的”，没有真假，不是命题。

感叹句（单纯抒发情绪）→ 不是命题
多么悲惨啊！
太可怕了！
👉单纯情绪宣泄，没有做出可判断真假断言。

注意区分：带感叹号的句子不一定都不是命题。
“每年有一千万儿童死于贫困！”—— 这是带感叹语气的陈述句，依然是命题，可以判断真假。只是加了情绪语气。
```
[我们使用命题这种建筑基块构造论证。在任一论证中，我们都是在一个或者更多其他命题的基础之上断定一个命题]，这样做就形成一个推论(inference)：一个命题被从一个或多个其他命题推出

[逻辑学家分析这些命题之间的关系，考察一个推论的起始命题与结束命题。这样的一个命题簇就构成一个论证]。论证是逻辑学所关心的主要对象。
