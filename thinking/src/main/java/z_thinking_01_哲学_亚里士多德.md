# 工具论
## 同一律
管「概念不乱跑」，解决偷换话题、歪曲定义
```aidl
核心规则：讨论全程，名词、标准、定义保持不变，不能悄悄换意思。
```
## 矛盾律
管「不自我冲突」，解决精神内耗、双重标准、自相矛盾
```aidl
双重标准是典型违反矛盾律：
对自己：迟到是小事；对别人：迟到极不尊重人。
同一事件 “迟到”，两套评判标准，形成矛盾。
```
## 排中律
管「拒绝模糊逃避」，解决选择困难、和稀泥、不敢做判断
核心规则：要么 A，要么非 A，不存在 “既不是 A 也不是非 A” 的中间状态
```aidl
场景 2：识人辨人，停止自我欺骗
纠结：这个人说不上靠谱，也不算不靠谱。
排中律：以 “长期行为是否守信” 为标准，本质只有两类：可靠 / 不可靠；
时而靠谱只是场景差异，本质有确定答案，不要用模糊感逃避现实。
```

## 三段论形式第一公理
大前提、小前提、结论
全部集合所拥有的属性，其中每一个个体必然拥有；全部集合不具备的属性，个体也不具备。
